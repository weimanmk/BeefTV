# Android 手机分支

此分支为实验性个人自用移植，保留上游许可与署名，不是官方 Android 发布。

## 打包和安装

GitHub Actions → **Android APK** → **BeefTV-Mobile-Release**。配置持久签名后安装 `BeefTV-Mobile.apk`；`app-release-unsigned.apk` 未签名，不能直接安装。**BeefTV-Mobile-APK** 中的 debug APK 仅用于 CI 冒烟，不用于长期升级。

在仓库 Actions Secrets 配置 `ANDROID_KEYSTORE_BASE64`、`ANDROID_KEYSTORE_PASSWORD`、`ANDROID_KEY_ALIAS`、`ANDROID_KEY_PASSWORD`、`ANDROID_SIGNING_CERT_SHA256`。工作流先验证签名配置与 `android/signing-certificate.sha256` 中的 0.1.5 证书一致，再构建和签名；缺少配置、密钥错误或指纹变化均会失败，不再把未签名包当作成功交付。私钥必须单独备份，绝不能提交到仓库。固定包名和递增 versionCode 用于后续覆盖升级。

0.1.4 及更早版本使用临时 runner debug 密钥，无法恢复其私钥；新签名不能覆盖那些旧签名。迁移前先导出画布和素材，验证备份可读，再安装新签名版本。固定签名只能保证使用该密钥的后续版本升级。

Android 8.0 以上，支持 arm64-v8a 真机和 x86_64 模拟器。需要近期版本的 Android System WebView；推荐 Android 10 以上。
首次打开先完成工作区初始化，再在模型渠道设置中填写自己的模型服务。仓库和 APK 均不包含用户密钥。

## 架构与数据

React 生产资源和官方模型渠道协议插件嵌入 Go 共享库，通过 JNI 启动 SQLite 和原有工作区 API。协议插件按内容指纹释放到应用私有目录。系统 WebView 连接手机回环地址；不要求运行电脑或外部 BeefTV 服务器。
0.1.1 使用独立包名 `com.weimanmk.beeftv.mobile`，可与 0.1.0 并存。旧版草稿不会自动迁移：先在旧版“下载当前内容”导出，再在新版画布库“导入画布”。不要在备份成功前卸载旧版或清除数据。
地址固定为 `127.0.0.1:18790`，以保持浏览器存储的稳定来源，并与旧版端口区分。端口冲突会显示启动错误，不会接入其他服务。
每个进程生成随机会话，所有 API、媒体和界面请求必须携带 HttpOnly / SameSite=Strict Cookie；拒绝非本机 Host 和跨域 Origin。
通过本机会话校验后，仅为 `canvas.document.commit`、`canvas.task.bind` 和 `conversation.message.attach` 三个 UI POST 操作在后端附加 owner 身份。凭据不进入前端、不出现在 URL，不放行客户端注册或任意操作。
WebView 的明文 HTTP 仅放行回环地址。后端模型中转沿用原项目网络策略，建议外部渠道使用 HTTPS；手机上的 localhost 指手机自身，不是电脑。文件选择和保存使用 Android 系统文件对话框，不申请广泛存储权限。
数据库、渠道设置、素材在应用私有目录。未启用系统云备份；卸载会清除数据。系统结束进程时任务会中断，应用不提供后台常驻服务。

## 首版边界

- 复用原有窄屏导航和画布触控缩放；接入系统文件选择、原文件下载、返回键、视频全屏及屏幕安全区域。
- 原桌面 Node 助手宿主、外部插件可执行程序、原生 FFmpeg/ffprobe、深度采集和本机桌面集成尚未移植。这些功能不能按桌面版验收。
- 0.1.5 改为完整媒体资源构建，打包浏览器 FFmpeg、人脸识别和 3D 资源；手机时间线使用浏览器 FFmpeg，隐藏无法执行的原生服务端渲染入口。资源包含不等于所有设备性能验收通过。
- 导出文件通过认证的本地 handoff 暂存，原始文件名独立传递，交给系统文件对话框。写入并关闭目标流后才回报 saved；取消回报 cancelled，失败回报 failed。完成后清理 handoff 文件；视频导出需额外临时空间。
- 麦克风录音使用 Android 运行时授权，仅向本地工作区开放。相机直拍未接入，素材通过系统文件选择器导入；扩展名筛选会转成系统支持的 MIME 类型。
- 手机构建不默认打开桌面 Agent，画布隐藏其入口；设置页显示当前手机能力边界。
- 对话 Markdown、分镜素材和字幕下载延迟回收 Blob 地址，给 Android 下载回调留出读取时间。
- 窄屏模型设置按钮支持换行；素材类型与排序操作分行显示，生成历史网格随屏幕宽度收缩。模拟器同时断言这些控件不被视口裁切，并保留主要页面截图。
- 模型生成需要用户可用的渠道、网络和额度；构建测试不会调用付费模型。

## 本地构建

在 Linux 安装项目要求的 Go、Bun、Node.js 24、JDK 17、Gradle 8.11.1、Android SDK 35 和 NDK 28.2.13676358，并安装 Playwright Chromium 后：

```sh
export ANDROID_HOME=/path/to/android-sdk
bash scripts/build-android.sh
```

流程先构建前端并运行移动 HTTP 边界测试，再为两种架构编译 Go 共享库，最后生成 APK。
工作流还运行画布归档恢复、历史恢复、导出完整性、渠道协议和指针交互专项测试。Android 35 模拟器检查模型配置修订冲突、画布与素材重启持久化、WebView 上传、文件字节一致性、素材和文件夹增删改、历史恢复、主要页面、麦克风和 34MB 导出缓存；取消系统保存后检查临时文件清理。真实付费模型生成不在自动验收范围。
CI 的录音检查使用 Chromium 模拟音源，保留 Android 与 WebView 的权限校验；不代表真机麦克风音质验收。模拟标志只设置在临时测试模拟器中，不打进 APK。
native 库使用 16KB ELF 对齐。`android/app/src/main/jniLibs`、Gradle 缓存和 APK 均不提交源码。


### 0.1.3 手机显示修复

APK 使用 sensorLandscape，允许两个横屏方向。手机菜单使用独立 Drawer，不再被页面裁切，且不继承桌面折叠状态。模型服务弹窗使用单一滚动容器，低高度下可滚动访问输入框和操作按钮。小于 1024px 的导演台默认收起场景面板，属性面板通过顶部“场景属性”按钮浮层打开，左侧工具栏支持滚动。

Android 冒烟测试新增横屏方向、菜单展开/关闭/导航、模型表单滚动可达、导演台视口尺寸和面板切换检查与截图；不调用付费模型服务。

### 0.1.5 同步与回归范围

补回桌面版参考素材 S3 对象存储设置和上传：使用同一 referencestorage 实现、加密配置和素材归属检查，原始 Secret Key 不回传前端。按需在生成时将本地参考素材转换为可公开读取的链接；需要用户自己的存储服务。未进行真实付费存储上传验收。

合入 fork main 的 v2.0.3 超分超时与错误分类修复。手机设置提供紧凑/舒适密度，默认 13px 根字号和 30px 常规 AntD 控件；桌面尺寸保持原值。画布百分比仍表示真实画布比例，不伪造 100%。节点和背板尺寸手柄使用 Pointer Events、pointer capture 和 pointercancel，兼容触摸与鼠标。

新增无付费模型的 desktop / Android touch Chromium 组件回归和 Go 文件名、字节、权限、取消/保存回执测试。自动化浏览器测试不能替代 Windows/macOS 安装版或 Android 真机验收。此前 Android CI 模拟器出现离线，原有 smoke job 保留诊断；未取得通过证据前不能写成实机回归完成。

### 0.1.6 同步基线与检查入口

同步桌面 v2.0.5 及上游 `bdaa37fb9ceed6f3e67338ac02aa592c883b0e6e`，包括画布 LOD 与视口修复、模型协议与凭证提示、生成结果恢复、视频与超分任务取回，以及结算字段的 v27 数据库迁移。上游拆分提示词组件后，手机的 13px 默认文字、双行紧凑输入区和展开高度继续保留在对应模块。

完整手机前端由真实本地 Go 工作区提供，使用独立 Node/Playwright 脚本检查首页抽屉、横屏模型表单和导演台面板，并保留截图。此路径不替换业务 API、不读取用户数据库、不调用付费模型。Linux 工作流另外构建桌面包并检查 CLI 和原生窗口；Android smoke 检查打包后的 WebView。应以相应工作流的最终结果为准，不能将测试入口存在当作验收通过。

签名预检先核对固定证书，再进行正式签名并验证成品 APK。覆盖升级适用于已安装同一 0.1.5 固定证书的版本；调试包和旧临时签名不在这个范围内。
